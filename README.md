# 🍽️ Restaurant Website

A modern and responsive **static restaurant website** built using HTML, CSS, and JavaScript. The website provides a simple and attractive online presence for a restaurant, including its menu, services, location, and contact information.

## 📌 Features

* 🏠 Attractive homepage
* 🍕 Restaurant menu section
* 📖 About the restaurant
* 🛎️ Services section
* 📸 Food/gallery section
* 📍 Location information
* 📞 Contact section
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* ⚡ Fast-loading static website

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No server or database is required.

## 💻 GitHub Pages

This project can be hosted for free using **GitHub Pages**.

1. Upload the project to GitHub.
2. Go to **Settings → Pages**.
3. Select the `main` branch.
4. Select `/root` as the folder.
5. Click **Save**.
6. Your website will be available through your GitHub Pages URL.
